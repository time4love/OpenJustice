How a bar is computed

Full

The check ran, its code has not moved since, and it held. PASS_WITH_KNOWN_LEGACY counts — a correct non-zero exit is not a failure.

Half

Stale. It ran and passed, but files it depends on have changed since. The proof no longer covers the code.

A sliver

Either no check exists for this level's invariant, or none has ever been recorded. Honest, and the most common state here.

A level scores its weakest check

Never its best. One unchecked clause is enough for a level's claim to outrun its evidence.
