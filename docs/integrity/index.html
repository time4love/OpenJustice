Shared foundation, Levels 3–6. All four rest on one substrate decision: the factual layer is Readability's article (fullText), not the payload as served. Level 3's anchor attested it; Level 4's chrome is invisible because the differ reads it; Level 5's contradictions came from its granularity; Level 6's claims are stitched by it. They move together, and one decision — moving the differ off fullText — addresses three at once.

How a bar is computed

Full

The check ran, its code has not moved since, and it held. PASS_WITH_KNOWN_LEGACY counts — a correct non-zero exit is not a failure.

Half

Stale. It ran and passed, but files it depends on have changed since. The proof no longer covers the code.

A sliver

Either no check exists for this level's invariant, or none has ever been recorded. Honest, and the most common state here.

A level scores its weakest check

Never its best. One unchecked clause is enough for a level's claim to outrun its evidence.

What this predicts

Levels 7, 8 and 9 will behave like Level 6. All three ask the same question in different clothes — does this artefact say something true about the page? Each is likely to find something on first honest execution. Their statuses will not move backwards; the confidence behind the earlier ones should widen. Discovery here is a function of first-time execution, not decay — four instruments ran for the first time on 2026-08-30 and all four found something. That backlog is finite.
